# localai
A Claude Code-like terminal agent that runs entirely on your local machine using Ollama. It can execute shell commands, read and edit files, and maintain conversation context — with security guardrails so it doesn't nuke your system.

## Features
- **Environment-aware:** Gathers context on startup (cwd, git status, python env, disk, etc.) so it knows where it is before you say anything.
- **Shell execution:** Runs commands and feeds output back into the conversation. Dangerous commands require confirmation, hard-blocked ones are refused outright.
- **File operations:** Read, write, and surgical find-and-replace edits. Warns before overwriting existing files.
- **Rolling context:** Keeps the last 20 messages in memory so it doesn't lose track mid-task.
- **Write sandbox:** Optionally restrict file writes to a specific directory tree.
- **Tool injection protection:** Strips fake tool blocks from command output before they hit the model context.
- **One-shot shell mode (shellgpt-style):** `ai <what you want>` turns plain English into a single shell command, shows it with a one-line explanation, and only runs it if you confirm. Uses Ollama's structured output (JSON schema), so even small models can't break the parsing with chatty replies.
- **zsh widget:** Type a request on the command line, press Ctrl+G, and the line is replaced with the generated command. It never executes anything on its own.

## Installation

Requires Python 3.9+ and a running [Ollama](https://ollama.com) instance.

```bash
git clone https://github.com/arshgudrzi/LocalAgent ~/LocalAgent
cd ~/LocalAgent
ollama pull qwen2.5-coder:7b

python3 -m venv ~/.venvs/localai
~/.venvs/localai/bin/pip install ollama

mkdir -p ~/.local/bin
cat > ~/.local/bin/localai <<'EOF'
#!/bin/sh
exec ~/.venvs/localai/bin/python ~/LocalAgent/localai.py "$@"
EOF
chmod +x ~/.local/bin/localai
```

Add to `~/.zshrc` (or `~/.bashrc`, minus the `noglob`):

```zsh
export PATH="$HOME/.local/bin:$PATH"
alias ai='noglob localai'
```

## Usage

**One-shot mode** (like shellgpt):

```bash
ai list the 5 biggest files here
ai which process listens on port 8080
ai -m qwen2.5-coder:14b show git commits from last week
ai -p find all .log files    # print the command only, never run it
```

You always get a preview and an `[e]xecute / [a]bort` prompt. Default is abort.

**Agent mode** (shell, file read/write/edit, rolling context):

```bash
ai
```

Inside the chat: `clear` resets context, `model <name>` switches model, `exit` quits.

**Config via environment variables:**

```bash
LOCALAI_MODEL=qwen2.5:14b ai
LOCALAI_WRITE_ROOT=/home/you/projects ai
```

Notes: wrap requests containing apostrophes in double quotes, and put `--` before a request that starts with a dash. Ollama must be running (`ollama serve`).

## zsh widget (Ctrl+G)

Add to `~/.zshrc`:

```zsh
ai-widget() {
  [[ -z $BUFFER ]] && return
  local req=$BUFFER cmd
  BUFFER="# thinking..."; zle -R
  cmd=$(localai --shell --print "$req" 2>/dev/null)
  BUFFER=${cmd:-$req}
  CURSOR=${#BUFFER}
}
zle -N ai-widget
bindkey '^g' ai-widget
```

Type what you want, press Ctrl+G, review the command, press Enter yourself.


Switch model on the fly:
```bash
LOCALAI_MODEL=qwen2.5:14b python localai.py
```

Sandbox file writes to a directory:
```bash
LOCALAI_WRITE_ROOT=/home/arash/projects python localai.py
```

Inside the chat: `clear` resets context, `model <name>` switches model, `exit` quits.

## Security model

This tool executes commands generated by an LLM. Treat it accordingly.

- Nothing runs without explicit confirmation in one-shot mode. The Ctrl+G widget never executes.
- The dangerous/blocked pattern lists are regex guardrails against accidents, **not a sandbox**. They can be bypassed by obfuscation (quoting tricks, command substitution, encoding). Read the command before you confirm.
- `LOCALAI_WRITE_ROOT` restricts file writes and edits only. It does not restrict reads or what shell commands can touch.
- Command output is stripped of fake tool blocks before being fed back to the model, but small local models are still easy to prompt-inject. Don't point the agent at untrusted files or web content.
- Everything stays local. No data leaves your machine unless you use Ollama cloud models.
